# Bot Zueiro Grupo WhatsApp 💜

## Comandos
`!piada` - Manda piada aleatória
`!sorte` - Sorte do dia
`!audio 1` até `!audio 5` - Manda áudio
Oi, Bom dia, Tchau - Ele responde sozinho

## Como rodar
1. npm install
2. Colocar 5 audios em /audios com nome audio1.mp3 até audio5.mp3
3. npm start
4. Escanear QR code
